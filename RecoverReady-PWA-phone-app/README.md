# RecoverReady PWA — phone simulator only

This version uses the original RecoverReady phone simulator as the app itself. The outer presentation website, demo introduction, feature cards, and readiness-index section are not included. The five original simulator tabs and interactions are retained.

## Update your existing new repository

1. Open your `RecoverReady-PWA` repository on GitHub.
2. Choose **Add file → Upload files** (or use the repository's upload page).
3. Upload the *contents* of this folder: `index.html`, `manifest.json`, `sw.js`, `icons/`, and `README.md`. Keep `index.html` at the repository root, not inside another folder.
4. Commit the changes to the `main` branch. When GitHub asks whether to replace `index.html`, confirm the update by committing the new version.
5. Wait for GitHub Pages to redeploy.

## On iPhone

Open the GitHub Pages site in Safari. If an older version remains, remove the old home-screen shortcut and add it again from Safari's Share menu → **Add to Home Screen**. If a cached old version still appears, close the app, reopen the website in Safari, then launch the icon again.

This is a PWA, not a native iOS app. The sample route details and scripted support replies are illustrative, not verified directions or clinical advice.
